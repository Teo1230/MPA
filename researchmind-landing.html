ResearchMind is a multi-agent AI platform that analyses your research papers, surfaces hidden connections, generates evidence-backed hypotheses, and critiques scientific quality — all in one place.

The Three Agents
AGENT 01
⬡
Paper Analyzer
Ingests raw paper text and extracts structured knowledge: title, summary, key concepts, methodology, datasets, findings, and limitations — as typed JSON in seconds.
Extraction JSON output LLaMA 3.1
AGENT 02
◈
Synthesis Agent
Takes all Agent 1 outputs, identifies cross-paper themes and specific connections, surfaces research gaps, and generates 3 novel, testable hypotheses backed by evidence from your library.
Cross-paper Hypotheses Gap analysis
AGENT 03
🔬
Paper Critic
Critically evaluates each paper's methodology rigour, statistical soundness, reproducibility, and novelty. Returns a credibility score (0–10) with breakdown, weaknesses, and suggested improvements.

Features

Research intelligence,
actually built.

Every feature below is live and working in the MVP — no mockups, no future roadmap items.

🕸️

Knowledge Graph

Every paper you add becomes a node. Shared concepts draw edges between papers, revealing thematic clusters and research overlaps at a glance. Built with D3.js — fully interactive.

💡

Synthesis & Hypotheses

Agent 2 reads all your papers together and produces specific cross-paper connections, research gaps, and 3 novel testable hypotheses — citing paper titles in its reasoning.

→ Connection found
"Both papers target mental health via NLP — Paper A models adaptive states, Paper B extracts clinical markers with lightweight classifiers."

→ Research gap
No study combines adaptive state modelling with lightweight marker extraction for real-time clinical alerts.
🔬

Paper Critique (Agent 3)

Select any paper and get an instant quality assessment — methodology, statistics, reproducibility, novelty, and clarity — each scored 0–10 with a credibility verdict.

Library Chat

Ask any question across your entire paper library. The chat agent draws on every analyzed paper to give grounded, contextual answers — identifying which papers support each claim.

How it works

Three agents.
One pipeline.

1

Add your papers

Paste a PDF URL or type a paper title. ResearchMind fetches and sends the text to Agent 1, which extracts structured knowledge — concepts, methodology, findings, datasets — in seconds.

⬡ Paper Analyzer Agent
2

Agents analyse together

Run synthesis across your whole library. Agent 2 reads every paper, finds specific cross-paper connections, surfaces gaps, and proposes hypotheses. Run Agent 3 on any single paper for a quality critique.

◈ Synthesis Agent 🔬 Paper Critic
3

Explore & ask

Navigate the knowledge graph to see concept connections. Switch to the Chat tab and ask free-form questions across your library. Each paper's critique is saved so you can compare quality across your collection.

Technology Stack

Built on fast,
open-source tools.

Every component used in this MVP is free and open-source.

⚡
Groq API
Ultra-fast inference layer. Free tier available. Drives all three agents at runtime.
🦙
LLaMA 3.1 8B
Open-weight language model from Meta. Served via Groq. Strong academic reasoning.
🐍
FastAPI
Python async backend. Orchestrates the three agents, stores paper analyses in memory.
🕸️
D3.js
Force-directed graph layout for the interactive knowledge graph in the browser.
🌐
Three.js
WebGL-based 3D particle field on this landing page hero section.
🎞️
GSAP
Scroll-triggered animations and entrance transitions on the landing page.
🤖
AsyncGroq
Async Python client for Groq — enables concurrent agent calls without blocking.
📦
Pure HTML/JS
No React, no bundler. The entire frontend is a single HTML file with vanilla JS.
